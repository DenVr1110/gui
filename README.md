# CursorUI

Плагин для Paper 1.20.x: **меню с курсором мыши вместо сундуков**, **HUD** и **API** для других плагинов.
Игрокам не нужны моды и ресурспак. Это оригинальная реализация, не копия чужого плагина.

## Сборка

Нужны JDK 17+ и Gradle:

```
gradle build
```

Готовый файл: `build/libs/CursorUI-0.1.0.jar` → положить в `plugins/`.
Рекомендуемая версия сервера: Paper 1.20.2–1.20.6 (собрано против paper-api 1.20.4).
PlaceholderAPI необязателен (soft-depend).

## Как это работает

1. При открытии меню перед глазами игрока (на `distance` блоков) ставится вертикальная плоскость.
2. Игрок «замораживается» на месте (позиция фиксируется, повороты головы свободны).
3. Каждый пакет поворота головы превращается в луч, луч пересекается с плоскостью, и курсор переносится в эту точку.
   Ничего не опрашивается по тикам, поэтому курсор следует за мышью так быстро, как клиент шлёт пакеты.
4. Кнопки, панели, тексты и курсор рисуются Display-сущностями, видимыми только этому игроку.
5. Клики (ЛКМ/ПКМ) ловятся в том числе с пустой рукой: вокруг игрока ставится невидимая Interaction-сущность.

Закрытие меню: **Shift** (sneak), **F** (swap hands) или действие `[close]`.

## Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/cui open <меню> [игрок]` | открыть меню | `cursorui.open` (другому игроку: `cursorui.admin`) |
| `/cui close [игрок]` | закрыть меню | — |
| `/cui list` | список меню | `cursorui.open` |
| `/cui reload` | перезагрузить конфиги, меню и HUD | `cursorui.admin` |
| `/cui hud [on\|off\|toggle] [игрок]` | включить/выключить HUD | `cursorui.hud` |

У меню может быть своё право в поле `permission`.

## Меню (`plugins/CursorUI/menus/*.yml`)

Имя файла = id меню. Смотрите готовый `example.yml`. Координаты в «пикселях меню»: (0,0) — центр, x вправо, **y вверх**.
По умолчанию 100 пикселей = 1 блок (`pixels-per-block`).

Типы элементов: `panel`, `label`, `button`, `item`, `input`, `bar`.

| Поле | Для чего |
|---|---|
| `x, y, width, height, layer` | положение, размер, слой (больше = ближе к игроку и приоритетнее при клике) |
| `material`, `hover-material` | блок для фона (любой полный блок, например `*_CONCRETE`) |
| `text`, `hover-text`, `text-scale` | текст MiniMessage; `text-scale: 1.0` ≈ размер обычного текста |
| `actions`, `left-actions`, `right-actions` | действия при клике |
| `item`, `custom-model-data` | для `item` |
| `value`, `fill-material` | для `bar`: выражение вида `"{health}/{max_health}"` |
| `value-text`, `max-length`, `submit-actions` | для `input` (ввод через чат, `{input}` = введённое значение) |

Действия: `[player] cmd`, `[console] cmd`, `[close]`, `[menu] id`, `[message] текст`, `[actionbar] текст`, `[sound] ключ`.

Плейсхолдеры: `{player} {displayname} {health} {max_health} {food} {level} {world} {x} {y} {z} {ping} {online} {max_players} {tps}`,
`{input:<id элемента>}` и любые `%плейсхолдеры%` PlaceholderAPI.

> Осторожно с `{input}` в `[console]`-командах: введённый текст чистится от спецсимволов, но всё равно
> не отдавайте игрокам произвольные аргументы к опасным командам.

## HUD (`hud.yml`)

Без ресурспака HUD строится из **boss bar** (верх экрана) и **action bar** (над хотбаром).
Свободное позиционирование по пикселям (как в платных плагинах) потребует ресурспака и шрифтов, в версию 0.1 оно не входит.

## API

```java
CursorUIAPI api = Bukkit.getServicesManager().load(CursorUIAPI.class);

Menu menu = new Menu("shop").add(Element.panel("bg", 0, 0, 300, 160, "BLACK_CONCRETE").layer(0));
menu.add(Element.label("title", 0, 55, "<gold>Shop"));
menu.add(Element.button("buy", 0, 0, 160, 34, "<white>Buy apple")
        .materials("GREEN_CONCRETE", "LIME_CONCRETE")
        .onClick((player, element, click) -> player.sendMessage("Bought!")));
api.registerMenu(menu);
api.openMenu(player, "shop");
```

События: `MenuOpenEvent`, `MenuCloseEvent`, `MenuClickEvent` (отменяемые, где это имеет смысл).

## ВАЖНО: статус

Код **написан без возможности запустить сервер и даже скомпилировать против Paper API** (в среде не было сети).
Синтаксис проверен, но реальную компиляцию и игровое поведение нужно проверить у вас.
Вероятнее всего потребуется подкрутка отображения, для этого в `config.yml` есть секция `render`:

* всё меню зеркальное или невидимое → `render.yaw-offset: 180`
* текст выше/ниже, чем нужно → `render.text-y-offset`
* предметы зеркальные → `render.item-flip: true`
* курсор-картинка смещена → `cursor.item-offset-x / item-offset-y`

## Ограничения

* Задержка курсора минимальна, но не нулевая: Display-сущности ходят по сети, а клиент плавно не интерполирует телепорт.
  Настоящий «zero delay» с картинками больше 256×256 и текстовым вводом в самом клиенте требует ресурспака/шейдеров.
* Игрок фиксируется через `PlayerMoveEvent`. В воздухе/при падении возможна «дрожь», лучше открывать меню на земле.
* Меню всегда вертикальное и строится по направлению взгляда (yaw) в момент открытия.
* Состояние «HUD выключен» хранится в памяти и сбрасывается при перезапуске.
